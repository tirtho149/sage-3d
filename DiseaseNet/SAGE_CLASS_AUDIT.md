## 3. Caveats (must be read with every result)

- **Keyword tiers are a transparent first pass, not biology.** Geometry/appearance tiers come
  from regular expressions over the verbatim KB text (`GEOMETRY_TERMS`, `APPEARANCE_TERMS`
  in the script). Some matches will be wrong (a "sunken" lesion is mostly an appearance
  cue in a photo). Protocol F2 biological review must check the Stage-0 classes.
- **Single-source classes: 94 of 195 eligible classes come from one source dataset.**
  A classifier can learn the source's photographic style instead of the disease. Phase 1
  must report a source-only shortcut check (protocol K2).
- **Label artefacts exist**, e.g. `*::alternaria_black_molds_stem_cankers` (7,939 potato
  images) — excluded from Stage 0; a taxonomy decision is needed before Stage 2.
- **Bug found and fixed during the audit:** `plant_organ` is sometimes a stringified list
  (`['foliar', 'stem']`) and uses "foliar" for leaves; the first parse excluded 525 classes as
  "organ not reconstructable" (including Tomato Septoria, 19k images). Fixed; numbers above
  are from the corrected run.
