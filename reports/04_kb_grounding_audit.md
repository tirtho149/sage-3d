## Grounding findings
1. **Peach Leaf Curl.** Stage 0 = {distorted, thickened, puckered} + reddish/purple cast. Powdery grey (stage 1) and yellow/brown drop (stage 2) are prohibited for this stage. The interim `kb` prompt mixed stages 0 and 1; arm F keeps that prompt only for comparability. **“Curl” occurs only in the disease name, not in the cited text, so no curl operator is used.**
2. **Tomato Leaf Mold.** No geometric phrase. The mold is on the **lower** leaf surface, but SAM 3D leaves are a single Gaussian sheet, so upper and lower sides cannot differ (see report 06).
3. **Corn Smut.** Outgrowth (galls) only. The cited text gives a size range (1–30 cm), but the assets are not metric, so size cannot be enforced.
4. **Citrus Canker (fruit).** The only geometric claim (“crater-like depression”) is hedged (“may manifest”), so it is excluded. Corky texture has no operator. The leaf spec (specimen 0004) is appearance-only.
5. **Mango Anthracnose.** “Sunken point-sized spots” mixes geometry and appearance in one phrase, so it cannot be split without paraphrase. The geometry arm uses `depress`, but the depression detector is non-specific (report 03), so its recall is not scored.

## Metric definitions and deviations
- **Geometry:** `src/metrics/kb_grounding.py` (recall and unsupported rate over specific detectors; thresholds in `configs/evaluation/attribute_thresholds.json`).
- **Appearance:** `src/metrics/appearance_kb.py`. Lab shifts with an a-priori T = 5. Recall and unsupported rate are over scorable colour terms. The lower-surface ratio uses the bottom vs top view.
- **Deviation (logged).** “Pale” was first defined as ΔL* ≥ T alone. On Peach 0087, that counted saturated purple lightening as pale. It was corrected to ΔL* ≥ T and Δchroma ≤ 0 after seeing those 2D outputs.
- **Deviation 2 (logged, post hoc, changes conclusions).** “Purple” was first mapped to Δa* ≥ T (“redder”). That cannot detect a red leaf turning purple, which is a blue shift. A separate `purpler` detector (Δb* ≤ −T and Δa* ≥ 0) was added, and a phrase naming several colours (“reddish **or** purple”) is satisfied by any of them. This was decided after seeing that GE arms F and K moved Peach 0087 by Δb* ≈ −7.5. On 0087, F and K appearance recall changes from 0 (v1) to 1 (v2); E stays 0. Both versions are reported (`appearance_recall_v1_redder_only`).
- **Not automatable here:** organ localisation (all edits are whole-organ), lesion shape (“oval”, “point-sized”), texture (“velvety”, “oily”, “corky”) and expert validity. These are reported as **not scored**; expert review is BLOCKED (no raters).
